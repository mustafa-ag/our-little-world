# Asset Licenses

This file tracks all third-party assets used in Our Little World.
All new assets must be added here before being committed to the repository.

## License requirements

- **Preferred:** CC0 (public domain) — no attribution required
- **Acceptable:** CC BY 4.0 — attribution required, record in table below
- **Acceptable:** MIT / Apache 2.0 for code-derived assets
- **Not acceptable:** CC BY-SA, CC BY-NC, or copyrighted assets without explicit written permission

## Notes

- All character models, building models, environment assets, and textures in `public/assets/` are currently original work authored by the project's Blender pipeline (`tools/blender/`).
- No third-party textures, models, or images have been incorporated from external sources.
- Before adding any external asset: verify its license, add a row to the table above, and keep a copy of the license notice alongside the asset if required.
- Do not copy textures from reference images, photographs, screenshots, or assets found via image search.
- When in doubt, use CC0 assets only (e.g. from ambientcg.com, polyhaven.com, or OpenGameArt CC0 collection).
